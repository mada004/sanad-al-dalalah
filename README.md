# سند الدلالة

**من الادعاء إلى الدليل، قبل النشر**

سند الدلالة هو أداة مدعومة بالذكاء الاصطناعي تساعد كتّاب ومحرري المحتوى التعريفي بالإسلام على التحقق من مدى دعم المصادر للادعاءات المكتوبة قبل نشر المحتوى.

## المشكلة

وجود مصدر موثوق لا يعني بالضرورة أن صياغة الادعاء تعكس ما يثبته المصدر بدقة.

قد تظهر فجوات مثل:
- أن يكون الادعاء أوسع مما يدعمه المصدر.
- أن يكون الدعم جزئيًا.
- أن يحتاج الادعاء إلى سياق إضافي.
- أن يحتاج إلى مراجعة بشرية.

## كيف يعمل سند الدلالة؟

1. إدخال النص.
2. استخراج الادعاءات الأساسية.
3. استرجاع الأدلة من المصادر المحددة.
4. مقارنة كل ادعاء بالأدلة المسترجعة.
5. عرض حالة الادعاء والدليل والمصدر وسبب التقييم.
6. اتخاذ الكاتب أو المختص للقرار النهائي.

## حالات التقييم

- **Supported** — مدعوم
- **Partially Supported** — مدعوم جزئيًا
- **Needs Context** — يحتاج سياقًا
- **Needs Review** — يحتاج مراجعة

## التقنيات المستخدمة

### Backend
- Python
- FastAPI

### Source Retrieval
- Dorar.net

### Frontend
سيتم تحديث هذا القسم بعد اكتمال الواجهة.

### AI / Semantic Comparison
سيتم تحديث هذا القسم بعد اكتمال نموذج المقارنة الدلالية.

## حالة المشروع

المشروع حاليًا قيد التطوير.

تم حتى الآن:
- إنشاء Backend باستخدام FastAPI.
- إنشاء `/analyze` endpoint.
- استقبال النص وتقسيمه مبدئيًا إلى ادعاءات.
- استرجاع أدلة من Dorar.net.
- إرجاع الدليل واسم المصدر وموضعه.

قيد التطوير:
- استخراج الادعاءات باستخدام الذكاء الاصطناعي.
- المقارنة الدلالية بين الادعاء والدليل.
- التصنيف النهائي للادعاءات.
- ربط الواجهة بالـBackend.
- الاختبار النهائي.

## الاختبار

يتم اختبار النظام باستخدام حالات مرجعية تغطي:

- Supported
- Partially Supported
- Needs Context
- Needs Review

وسيتم توثيق نتائج الاختبارات بعد اكتمال النسخة القابلة للاختبار.
